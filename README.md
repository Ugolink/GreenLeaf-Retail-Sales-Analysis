# GreenLeaf Retail Stores Nigeria
## Sales Performance Analysis Dashboard

### Project Overview
This project uses Microsoft Excel to analyze retail sales data
from January to December 2025.

### Business Objectives
- Evaluate sales performance across branches.
- Identify the highest-performing product categories.
- Analyze monthly sales trends.
- Examine discounts across branches.
- Develop actionable business recommendations.

### Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Interactive slicers
- Excel formulas and KPI cards

### Key Performance Indicators
- Total Sales: ₦152,589,401
- Total Discount: ₦5,898,974
- Total Quantity Sold: 9,614
- Total Transactions: 1,500
- Average Order Value: ₦101,726

### Key Insights
- Kano recorded the highest branch sales at approximately ₦26.25 million.
- Groceries generated approximately ₦30.34 million in sales.
- January recorded the highest monthly sales at approximately ₦14.86 million.
- Enugu recorded the highest branch discount rate at 4.70%.

### Dashboard Features
- Six KPI cards
- Four visualizations
- Interactive branch slicer
- Branch, category, discount, and monthly trend analysis
